# (painel)

Área logada da aplicação — dono/equipe da clínica, estética ou studio.

Aqui vive o painel administrativo, por exemplo:

- Dashboard
- Agenda interna, financeiro, fiscal, convênios (quando implementados)
- Configurações da conta/tenant

Rotas deste grupo herdam o layout definido em `layout.tsx` (ex: sidebar,
topbar). Nenhuma funcionalidade de negócio, autenticação ou proteção de
rota foi implementada ainda — apenas a pasta e o layout base.
