# (publico)

Área pública da aplicação — acessível sem autenticação.

Aqui vive o portal voltado ao cliente final da clínica/estética/studio, por exemplo:

- Landing page institucional
- Portal de autoagendamento (o cliente final marca um horário sem precisar
  logar na área administrativa)
- Páginas de confirmação/cancelamento de agendamento via link público

Nenhuma funcionalidade de negócio foi implementada ainda — apenas a pasta e o
layout base para este grupo de rotas.
