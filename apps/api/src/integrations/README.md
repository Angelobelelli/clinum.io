# integrations

Integrações com serviços externos, isoladas do restante do domínio por
adapters/clients dedicados — para que os módulos de negócio não dependam
diretamente de SDKs de terceiros.

Exemplos de integrações previstas (nenhuma implementada ainda):

- **google-calendar/** — sincronização de agenda com o Google Calendar
- **whatsapp/** — envio de notificações/lembretes via WhatsApp
- **pix/** — cobrança e conciliação via Pix
- **nota-fiscal/** — emissão de nota fiscal eletrônica junto a provedores

Esta pasta está vazia por enquanto — apenas reserva o lugar na arquitetura.
